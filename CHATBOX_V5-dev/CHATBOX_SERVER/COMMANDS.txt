────────────────────────────────────────────────────────────────────────────────
 1. ENROLL A FACE  (do this first before running the main loop)
────────────────────────────────────────────────────────────────────────────────

  # Enroll one person — opens a webcam window, counts down 3 s, then captures
  # 15 frames. Look straight at the camera during capture.
  python3 -m modules.face_webcam.webcam_loop --mode enroll --name Jay

  # Enroll with more capture frames (better accuracy)
  python3 -m modules.face_webcam.webcam_loop --mode enroll --name Jay --n-captures 30

  # Enroll a second person
  python3 -m modules.face_webcam.webcam_loop --mode enroll --name Peter

  # Enroll using a different camera (e.g. external USB cam = index 1)
  python3 -m modules.face_webcam.webcam_loop --mode enroll --name Jay --camera 1

  # Enrollments are saved automatically to faces.npz in the working directory.
  # Re-enrolling the same name UPDATES (averages) the existing embedding.


────────────────────────────────────────────────────────────────────────────────
 2. RUN THE MAIN LOOP
────────────────────────────────────────────────────────────────────────────────

  --- Standard (face reco + emotion, no LLM) ---

  python3 -m modules.face_webcam.webcam_loop

  --- With LLM chat (Ollama qwen2.5:7b must be running) ---

  python3 -m modules.face_webcam.webcam_loop --llm

  --- Full stack: LLM + hsemotion (recommended) ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion hsemotion

  --- Full stack for ELLEBOT persona ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion hsemotion --robot ellebot

  --- Use the larger, more accurate B2 emotion model (~12 ms/frame) ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion hsemotion-b2

  --- Use original EfficientNet emotion model (HQRAF, PyTorch) ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion efficientnet

  --- Faster tick (0.5 s) — KG + PAD updates twice per second ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion hsemotion --tick 0.5

  --- Looser face matching (lower threshold = accepts less-clear matches) ---

  python3 -m modules.face_webcam.webcam_loop --llm --threshold 0.65

  --- Different Ollama model ---

  python3 -m modules.face_webcam.webcam_loop --llm --model llama3.2:3b

  --- Full stack with ESP32 expression dispatch ---

  python3 -m modules.face_webcam.webcam_loop --llm --emotion hsemotion --esp32-host 10.42.0.100

  --- Headless (no OpenCV window, terminal output only) ---

  python3 -m modules.face_webcam.webcam_loop --llm --no-window

  --- External USB camera ---

  python3 -m modules.face_webcam.webcam_loop --llm --camera 1


────────────────────────────────────────────────────────────────────────────────
 3. IN-WINDOW KEYBOARD CONTROLS  (during --mode run)
────────────────────────────────────────────────────────────────────────────────

  T          Open chat box — type message → Enter to send to LLM
  E          Open enroll box — type name → Enter to enroll face from live frame
  Esc        Cancel current input box
  Backspace  Delete last character in input box
  Q          Quit


────────────────────────────────────────────────────────────────────────────────
 4. OLLAMA — START / CHECK
────────────────────────────────────────────────────────────────────────────────

  # Check Ollama is running
  curl http://127.0.0.1:11434/v1/models

  # Start Ollama server (if not already running as a service)
  ollama serve

  # Pull the default model (one-time, ~4 GB)
  ollama pull qwen2.5:7b

  # Pull a lighter model for slower machines
  ollama pull llama3.2:3b

  # List downloaded models
  ollama list


────────────────────────────────────────────────────────────────────────────────
 5. ALL CLI FLAGS — QUICK REFERENCE
────────────────────────────────────────────────────────────────────────────────

  Flag                Default         Description
  ──────────────────────────────────────────────────────────────────────────────
  --mode              run             "run" or "enroll"
  --name              (none)          Person name — required for enroll mode
  --robot             chatbox         Robot persona: "chatbox" or "ellebot"
  --faces             faces.npz       Path to face embedding database
  --camera            0               Camera device index
  --threshold         0.75            Cosine similarity threshold (0–1)
  --tick              1.0             KG/PAD pipeline tick interval in seconds
  --n-captures        15              Frames captured per enroll session
  --llm               (off)           Enable Ollama LLM verbal responses
  --model             qwen2.5:7b      Ollama model name
  --emotion           hsemotion       Backend: hsemotion / hsemotion-b2 / efficientnet
  --no-window         (off)           Headless mode — no OpenCV window
  --kg                kg_state.json   KG persistence file (auto-saved on quit, loaded on start)
  --esp32-host        (disabled)      ESP32 IP for TCP expression dispatch (e.g. 10.42.0.100)
  --esp32-port        8888            ESP32 TCP port

────────────────────────────────────────────────────────────────────────────────
 7. TIER PROGRESSION  (how long to reach each KG relationship tier)
────────────────────────────────────────────────────────────────────────────────

  Tier       Condition                    Approx ticks (happy emotion, tick=1.0s)
  ──────────────────────────────────────────────────────────────────────────────
  visitor    interaction_count >= 1       immediate on first recognition
  known      interaction_count >= 6       ~6 ticks
             OR rapport/trust > 0.45
  close      rapport/trust > 0.70         ~34 ticks of happy emotion
  unknown    not recognised               —

  delta per tick = 0.025 × PAD_Pleasure  (max delta = 0.025 when P=1.0)
